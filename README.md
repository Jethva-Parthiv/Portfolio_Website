# Jethva Parthiv — Personal Portfolio

This is a Next.js (App Router) TypeScript portfolio scaffold built with Tailwind CSS and Framer Motion. It is a custom, original implementation inspired by a reference site but contains unique content and design.

Quick start

```bash
cd Portfolio_2
npm install
npm run dev
```

Deployment

- Build: `npm run build`
- Start: `npm run start`
- Deploy on Vercel for optimal performance.

Notes

- Add a GitHub personal access token to a server route for authenticated API calls if you need private data or higher rate limits.
- Replace placeholder contact email and links with your real values.
